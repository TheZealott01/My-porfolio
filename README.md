# Rakesh Yadav Portfolio

Modern cybersecurity and software engineering portfolio built with React, Vite, Tailwind CSS, Framer Motion, and Lucide React icons.

## Live Portfolio

After GitHub Pages is enabled from the `main` branch and `/docs` folder, the portfolio will be available at:

```text
https://<your-github-username>.github.io/My-porfolio/
```

If the repository belongs to `TheZealott01`, the URL will be:

```text
https://TheZealott01.github.io/My-porfolio/
```

If the repository belongs to `pardhi183`, the URL will be:

```text
https://pardhi183.github.io/My-porfolio/
```

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The production site is generated into the `docs` folder for GitHub Pages.

## GitHub Pages Setup

In GitHub, open:

```text
Settings > Pages
```

Then choose:

```text
Source: Deploy from a branch
Branch: main
Folder: /docs
```

## Update And Push Changes

```bash
git add .
git commit -m "Update portfolio"
git push
```

## Easy Editing

Most portfolio content is stored in:

```text
src/data/portfolio.js
```

Update that file to change skills, projects, certificates, education, experience, contact details, and social links.
